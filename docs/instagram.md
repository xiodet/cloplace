# Бренды из Instagram: настройка

Сайт умеет показывать бренды, у которых нет своего магазина, а есть только Instagram. Раз в день сборщик берёт их последние посты через официальный API Instagram (Business Discovery) и кладёт фото на сайт со ссылкой на пост. Цен у таких брендов нет.

Чтобы это заработало, нужен ключ (токен) от твоего собственного аккаунта Instagram. Настройка делается один раз и занимает 15–20 минут. Названия кнопок у Meta иногда меняются, поэтому ориентируйся по смыслу.

## 1. Профессиональный аккаунт Instagram

В приложении Instagram: Настройки → Тип аккаунта и инструменты → Переключиться на профессиональный аккаунт. Подойдёт и «Автор», и «Бизнес». Это бесплатно, аккаунт может остаться закрытым от рекламы и без публикаций.

## 2. Страница Facebook, привязанная к Instagram

1. На facebook.com создай страницу (Меню → Страницы → Создать). Название любое, публиковать на ней ничего не нужно.
2. В настройках страницы найди «Связанные аккаунты» → Instagram и подключи свой аккаунт из шага 1.

## 3. Приложение Meta

1. Зайди на https://developers.facebook.com, войди своим Facebook и зарегистрируйся как разработчик.
2. My Apps → Create App. Сценарий «Other», тип «Business». Название любое.
3. Приложение можно оставить в режиме разработки (Development). Проверка приложения (App Review) не нужна, пока им пользуешься только ты.

## 4. Токен

1. Открой Tools → Graph API Explorer. Справа выбери своё приложение.
2. В поле «User or Page» выбери «Get User Access Token» и отметь разрешения:
   `instagram_basic`, `instagram_manage_insights`, `pages_show_list`, `pages_read_engagement`.
3. Нажми Generate Access Token и в окне подтверждения выбери свою страницу и свой Instagram.
4. Этот токен живёт около часа. Открой Tools → Access Token Debugger, вставь токен, нажми Debug, затем внизу Extend Access Token. Получится токен примерно на 60 дней.
5. Чтобы не обновлять токен каждые два месяца, можно получить бессрочный токен страницы: вернись в Graph API Explorer, вставь туда 60-дневный токен, выполни запрос `me/accounts` и скопируй значение `access_token` у своей страницы.

Какой токен использовать: сначала попробуй бессрочный токен страницы из пункта 5. Документация Meta говорит, что для Business Discovery нужен токен пользователя, поэтому если сборщик напишет, что токен не принят, положи вместо него 60-дневный токен из пункта 4 и обновляй его раз в два месяца (пункты 2–4 заново).

## 5. Положить токен в GitHub

Репозиторий → Settings → Secrets and variables → Actions → New repository secret.
Имя: `IG_TOKEN`. Значение: токен. Секрет не виден в открытом коде и в логах.

Никогда не вставляй токен в файлы репозитория и не присылай его в чат.

## 6. Добавить бренды

Для каждого бренда нужны две записи:

- в `src/data/brands.js` обычная карточка бренда с `website: null`, `instagram: 'имя_аккаунта'` и `shipping: []`;
- в `src/data/sources.js` строка `'id-бренда': { instagram: 'имя_аккаунта' },`.

Проще всего прислать список аккаунтов, и записи будут добавлены за тебя.

## 7. Запуск и проверка

Сбор идёт каждый день вместе с остальным. Запустить вручную: вкладка Actions → ingest → Run workflow. В логе шага `npm run instagram` будет по строке на бренд:

- `✓ бренд instagram @имя: 6 posts` значит всё хорошо;
- `✗ ... token was not accepted` или `token has expired` значит нужен новый токен (шаг 4);
- `✗ бренд instagram @имя: ...` у одного бренда обычно значит, что аккаунт личный, а не профессиональный, или закрыт возрастным ограничением. Такие аккаунты API не отдаёт.

## Ограничения

- Работает только для профессиональных аккаунтов (бизнес или автор). У брендов они почти всегда такие.
- Видео с лицензионной музыкой и Reels с запретом на скачивание приходят без картинки и пропускаются.
- Берутся 6 последних постов на бренд. Фото копируются в репозиторий, потому что ссылки Instagram на фото перестают работать через несколько дней.
